# New Site — Online Calculator

A static, 44-page calculator site: 1 homepage tool + 35 guides (Algebra 7,
Percent and Decimal 16, Equivalent Fractions 12) + 2 reference pages (prime
numbers 1-100, square roots 1-100) + 3 info pages (About, Contact, Privacy)
+ 3 category pages. No build step, no database.

Live domain (2026-11-09): https://quickcalconline.com, used in
`sitemap.xml` and `robots.txt`. If the domain changes, update those two files.
Before launch, replace:
- The contact note in `contact.html` with the site owner's real contact details.
- The site name in the header if a brand name is chosen (page titles are
  deliberately keyword-first, with no brand in them).

All guide wording is original. Facts such as 1/4 = 0.25 = 25% are standard
mathematics, not copied text. The homepage also carries 5 quick tools with
steps, a comparison table, a fraction chart and an FAQ (added 2026-11-12),
all in original wording.
